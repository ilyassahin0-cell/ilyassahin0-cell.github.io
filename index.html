Papatya Ormanı Masalları – Yükleme Aracı

Papatya Ormanı Masalları, çocuklar için animasyonlu orman masalları yayınlayan bir YouTube kanalıdır.

Bu sayfa, kanal sahibinin kendi videolarını kendi YouTube kanalına yüklemek için kullandığı kişisel yükleme aracını tanıtır. Araç YouTube Data API'yi yalnızca şu işler için kullanır:

  • Kanal sahibinin ürettiği videoları kendi kanalına yüklemek,
  • Bu videoların başlık, açıklama, etiket ve kapak görsellerini ayarlamak,
  • Kanalın adını ve video sayısını okuyarak doğru kanala bağlanıldığını kontrol etmek.

Araç başka kullanıcılara açık değildir, başka kullanıcıların verilerine erişmez ve hiçbir veriyi üçüncü taraflarla paylaşmaz.

Bu araç YouTube API Hizmetlerini kullanır. Aracı kullanarak YouTube Hizmet Şartları'nı kabul etmiş olursunuz. Google'ın veri işleme ilkeleri için Google Gizlilik Politikası'na bakınız.

Daisy Forest Tales – Upload Tool

Papatya Ormanı Masalları ("Daisy Forest Tales") is a YouTube channel that publishes animated forest fairy tales for children.

This page describes the private upload tool the channel owner uses to upload their own videos to their own YouTube channel. The tool uses the YouTube Data API only to:

  • upload videos created by the channel owner to the owner's own channel,
  • set the title, description, tags and thumbnail of those videos,
  • read basic channel information (channel name and video count) to confirm it is connected to the correct channel.

The tool is not offered to other users, does not access other users' data and does not share any data with third parties.

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google processes data.
